# Changelog

## [1.0.0] - 2026-08-10

This is the first stable release of Kazusa Cognitive Core.

### Included

- Typed adapter-to-brain message envelopes and bounded queue intake.
- Retrieval, cognition, dialog, persistence, self-cognition, reflection, and
  scheduler ownership boundaries in one inspectable service core.
- Local control-console operations, health reporting, protected diagnostics,
  and delivery-receipt tracking.
- Platform-agnostic runtime entry points for local deployment and adapter
  integration.

### Operational boundary

Autonomous-contact surfaces remain permissioned preview contracts. A deployment
must explicitly configure permissions, dispatcher validation, adapter
availability, and auditability before enabling any autonomous delivery path.
